# 요구사항 정리

## 기능 요구사항
### 기본 로직
- [ ] 비상 근무자는 연속 2일 근무가 불가능하다.
- [ ] 특정 근무자가 연속 2일 근무하게 된다면 바로 다음 근무자와 순서를 바꿔 편성한다.
- [ ] 비상근무자는 평일 순번, 휴일 순번에 각각 1회 편성되어야 한다.
- [ ] 평일 -> 휴일로 갈때 연속 2일 근무라면 휴일인 근무자와 교대한다.
- [ ] 휴일 -> 평일로 갈때 연속 2일 근무하면 평일인 근무자와 교대한다.

### 근무자 관리


### 법정 공휴일
- [ ] 1월 1일 신정
- [ ] 3월 1일 삼일절
- [ ] 5월 5일 어린이날
- [ ] 6월 6일 현충일
- [ ] 8월 15일 광복절
- [ ] 10월 3일 개천절
- [ ] 10월 9일 한글날
- [ ] 12월 25일 성탄절

### 입력
- [ ] 월(숫자)과 시작 요일을 입력받는다.
- [ ] 연도는 고려하지 않고 2월은 28일까지 있다고 가정한다.
- [ ] 평일, 휴일 비상근무 순서 입력.
- [ ] 월과 시작요일이 유효하지 않을 경우 다시 입력하게 한다.
- [ ] 평일, 휴일 순번이 올바르지 않을 경우 다시 입력하게 한다.

### 출력
- [ ] 평일이면서 법정 공휴일인 경우에만 요일 뒤에 (휴일) 표기를 한다.
- [ ] 출력 완료시 프로그램 종료

### 예외처리
- [ ] [ERROR] 로 시작하는 에러메세지를 출력한다.
- [ ] 닉네임 중복되지 않게한다.
- [ ] 최대 5자로 제한한다.
- [ ] 최소 5명 ~ 최대 35명의 근무자가 유지되어야 한다.
