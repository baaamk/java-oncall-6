
우아한테크코스 웹 백엔드 최종 코딩테스트 대비를 위한 연습용 프로젝트: 개발자 비상근무

---

## 🎯 프로젝트 개요

우아한테크코스 최종 코딩테스트를 대비하기 위한 연습용 프로젝트입니다.  
개발자 비상근무 프로그램을 구현합니다.

---

## 📝 구현 기능 목록

### 1. 배정 정보 설정

- [x] **배정 날짜 정보 입력**
    - [x] 입력 안내 문구 출력 (형식: `비상 근무를 배정할 월과 시작 요일을 입력하세요> `)
    - [x] 비상 근무를 배정할 월과 시작 요일 입력
        - 월은 1 ~ 12 사이의 숫자로 입력받음
        - 시작 요일은 일, 월, 화, 수, 목, 금, 토 중 하나로 입력 받음
    - [x] **(예외 처리)** 배정 날짜 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`)
        - [x] 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - [x] 배정 월이 1 ~ 12 사이의 숫자가 아닌 경우
        - [x] 배정 요일이 일, 월, 화, 수, 목, 금, 토 중 하나가 아닌 경우
    - [x] 예외 발생 시, 배정 정보 설정 프로세스 다시 시작
    - [x] 비상 근무를 배정할 월과 시작 요일 정보 저장
- [x] **평일 비상 근무 순서 입력**
    - [x] 입력 안내 문구 출력 (형식: `평일 비상 근무 순번대로 사원 닉네임을 입력하세요> `)
    - [x] 평일 비상 근무자 이름 목록 입력
        - 닉네임 최대 5자
        - 최소 5명 이상의 근무자
        - 최대 35명의 근무자
        - 근무자의 이름은 중복될 수 없음
    - [x] **(예외 처리)** 근무자 목록 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`)
        - [x] 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - [x] 근무자의 수가 5명 미만인 경우
        - [x] 근무자의 수가 35명 초과인 경우
        - [x] 근무자의 닉네임이 5자를 넘는 경우
        - [x] 근무자의 닉네임이 중복되는 경우
    - [x] 예외 발생 시, 평일 비상 근무 순서 입력 프로세스 다시 시작
    - [x] 평일 비상 근무 순서 목록 정보 저장
- [x] **휴일(토요일, 일요일, 법정공휴일) 비상 근무 순서 입력**
    - [x] 입력 안내 문구 출력 (형식: `휴일 비상 근무 순번대로 사원 닉네임을 입력하세요> `)
    - [x] 휴일 비상 근무자 이름 목록 입력
        - 닉네임 최대 5자
        - 최소 5명 이상의 근무자
        - 최대 35명의 근무자
        - 근무자의 이름은 중복될 수 없음
    - [x] **(예외 처리)** 근무자 목록 유효성 검사: `IllegalArgumentException` (형식: `[ERROR] 유효하지 않은 입력 값입니다. 다시 입력해 주세요.`)
        - [x] 입력 값이 존재하지 않는 경우: 빈 문자열, 공백 문자열, Null
        - [x] 근무자의 수가 5명 미만인 경우
        - [x] 근무자의 수가 35명 초과인 경우
        - [x] 근무자의 닉네임이 5자를 넘는 경우
        - [x] 근무자의 닉네임이 중복되는 경우
    - [x] 예외 발생 시, 평일 비상 근무 순서 입력 프로세스 다시 시작
    - [x] 휴일 비상 근무 순서 목록 정보 저장

### 2. 비상 근무 배정
- [x] **날짜 정보에 따른 달력 구성**
  - [x] 연도는 고려하지 않으며, 매년 2월은 28일까지만 있다고 가정
  - [x] 입력 받은 월의 시작 요일은 입력 받은 요일로 지정
  - 휴일: 토요일, 일요일, 법정공휴일
  - [x] 법정공휴일
    - 1/1
    - 3/1
    - 5/5
    - 6/6
    - 8/15
    - 10/3, 10/9
    - 12/25
- [x] **근무 배정**
  - [x] 기본적으로 평일 근무 배정은 평일 순번, 휴일 근무 배정은 휴일 순번에 따라 배정
  - [x] 비상 근무자는 어떤 경우에도 연속 2일은 근무할 수 없음
  - [x] 순번상 특정 근무자가 연속 2일 근무하게 되는 상황에는, 다음 근무자와 순서를 바꿔 편성
    - 예를 들어, 수아가 평일인 목요일에 비상 근무를 서고,  
      다음 날인 금요일이 휴일이면서 순번상 또다시 수아가 근무해야 할 경우,  
      다음 휴일 근무자와 순서를 바꿔서 근무한다.

### 3. 배정 내역 출력
- [x] **비상 근무표 출력**
    - 배정 내역 출력 (형식: `{해당 월}월 {일}일 {요일} {근무자 닉네임}`)
      - 평일이면서 법정공휴일인 경우 요일 뒤에 `(휴일)` 이라고 표기 (예시: `금(휴일)`)
